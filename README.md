#Learning Curve
- In JavaScript, arr.push() adds one or more elements to the end of an array, while arr.pop() removes the last element from an array.
- Math.random() generates a random floating-point (decimal) number.
- Math.floor() takes any decimal number and rounds it down to the nearest whole integer
- Math.floor(Math.random() * 6) + 1 changes the value of an index from 0(inclusive) to 1.
- arr[] can take multiple primitive types.
